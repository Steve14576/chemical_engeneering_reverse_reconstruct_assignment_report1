## 零、由来与定位

- **触发任务**：`work/coffeehour_chat_refs/chat1_极限挑战逆天作业1_glm5.1.md`（化工实训"逆向演示装置管道拓扑"作业的全过程头脑风暴）。该文件是**头脑风暴素材**，内容跳脱、含情绪化吐槽与前后策略摇摆（如"降级写观察报告" vs "硬刚求解器"），一律按**未验证候选**对待，不作为项目定论。
- **用户真实处境（关键，来自最新拍板）**：
  1. **没时间**把一学期化工原理"长肌肉式"正经刷一遍；报告剩余时间不多不少。
  2. 但要**两样并存**：① 一份**全面的手册**（背后整套体系方法论都在、随时查得到）；② 一条**快速上手主线**（够看懂并干完这个作业）。
  3. 最怕两个极端：要么看不懂作业；要么只会做这个作业、对背后体系一无所知。
- **本课程的解法（双轨合一）**：
  - **地毯式全覆盖**保证"手册完备"（体系不缺项）；
  - **理解层次三档标注**（要能推导/手算 · 知道有这回事+什么时候查 · 建立直觉）保证"速通有重点"——读者不必把每条都练成肌肉，一眼看清哪些要练、哪些只需索引、哪些建立感觉即可。
  - **任务驱动**：以 chat1 的逆向作业为贯穿主线，化工原理概念只在"任务卡壳处"引入（WIICUFS 原则 8）。
- **索引 vs 正文的分工（用户明确要求）**：chat1 的任务弧线是**索引骨架**；**正文才是对任务的发散与补充的正式落点**——即把 chat1 里每一处"要靠化工原理才能判断"的空档，展开成系统、完整、不空降的正文。正文不是 chat1 的摘抄或复述。

## 一、目标与读者画像

### 1.1 课程目标（学完你能，行为化）

- [ ] 能看懂这套演示装置的常见化工设备（罐/泵/换热器/塔/分离设备），说出各自"在流程里承担什么角色、进出口有什么工艺约束"。
- [ ] 能把三个人的碎片观察整理成"带置信度的约束图"，用 networkx 建模、用 OR-Tools CP-SAT 求出若干候选拓扑，并统计稳定连接/不确定连接。
- [ ] 能读懂并绘制简化 P&ID / 流程图（实线=确认、虚线=推测、叉号=断/假管、问号=未知）。
- [ ] 能用化工原理常识写出"工艺软约束"（泵有吸入口/排出口、罐底出料、排放通低点、仪表是支路、换热器两侧进出口），并解释**为什么**（物理依据），而不是死记。
- [ ] 能写出一份**正常格式**、但把"确定/推测/无法判断"分开表达、含不确定性量化的研究报告；并说明本任务是 ill-posed（病态/信息不足）问题的边界。
- [ ] 手算层面：能算物料衡算、伯努利方程、简单McCabe-Thiele理论板数（全册版要求；子集版降为建立直觉）。

### 1.2 读者是哪一种（WIICUFS 原则 11）

- **画像**：工科学生，**会 python**（懂 networkx / or-tools / numpy 概念，chat1 里能接住这些），但**化工原理零基础**（chat1 原话："化工原理我们甚至没学过"）。
- **属于"完全踏入陌生领域、不知道自己不知道什么"那一档**：化工盲区里，他问不出没写的东西 → **必须靠地毯式覆盖兜底**（WIICUFS 原则 10），不能只写作业主线需要的部分。
- **时间受限**：所以要有"速通主线 + 手册兜底"的双轨，且三档理解层次帮他分配精力。

### 1.3 旧经验误会清单（带编程背景、无化工基础 → 每条对应未来某讲的"破误会"段）

| # | 误会（编程/直觉背景会这么以为） | 破除位置 | 正解 |
|---|---|---|---|
| M1 | 空间上离得近的两个接口 = 工艺上相连 | 第 02/03 讲 | 空间近≠工艺相连；要靠介质、压头、流向、设备角色判断 |

## 四、每讲认知思维链条（全册版；子集版按合并后调整）

> 格式：带着什么来 → 会自然产生什么疑问（按读者顺序） → 学完心智模型变成什么。写作时内容顺序按此链条走，不按作者知识组织走。

- **01 绪论**：带着"这会 python 但化工是黑箱、作业要逆拓扑"来 → 会问"化工原理到底研究什么？我这三个人几段管子怎么变成一张图？确定和猜的怎么分开？" → 学完建立"单元操作 + 物料衡算 + 带置信度的约束图"三个心智锚点，知道后面每讲是在给这张图补一类设备/一条约束。
- **02 流体流动**：带着"管子就是管子"来 → 会问"凭什么说这根管子里东西往哪流？压力、流向谁决定？三通旁路怎么算？" → 学完能用伯努利/连续性把"流向、压头、流量"讲成物理，而不是看图猜。
- **03 输送机械**：带着 M2"泵随便接"来 → 会问"泵进出口能不能反？为什么泵不能装太高？气蚀是什么？" → 学完把泵从"一段管子"升级成"有方向、有高度限制、有特性曲线的机器"，产出软约束。
- **04 P&ID**：带着"符号看不懂"来 → 会问"这些圈和线是什么？真假断管在图上怎么表达？仪表为什么是支路？" → 学完能读懂并手绘简化 P&ID，把 chat1 的线型语义落成正式图。
- **05 传热**：带着"换热器是个罐"来 → 会问"为什么换热器有两套进出口？热负荷怎么算？" → 学完识别换热器并写出"两侧进出口"软约束。
- **06 蒸馏**：带着"塔就是个高罐"来 → 会问"塔顶塔底为什么有冷凝器再沸器？回流是干嘛的？怎么算要几层板？" → 学完能画精馏 PFD、用 McCabe-Thiele 算理论板，识别塔设备全套连接。
- **07 吸收**：带着"吸收塔和精馏塔长得像"来 → 会问"吸收和精馏差在哪？操作线怎么画？液气比是什么？" → 学完能区分吸收/精馏，画操作线。
- **08 非均相分离**：带着"分离=过滤吧"来 → 会问"旋风分离器为什么是锥形？沉降和过滤本质差别？" → 学完能识别分离类设备并知其角色。
- **09 蒸发**：带着"蒸发=加热"来 → 会问"多效蒸发为什么省汽？蒸发器长什么样？" → 学完识别蒸发流程。
- **10 萃取与干燥**：带着"这两个不常见"来 → 会问"三角形相图怎么读？焓湿图那一堆斜线是什么？" → 学完对相图建立直觉、能识别萃取/干燥设备（不要求会算）。
- **11 拓扑逆向实战**：带着"到底怎么把碎片拼成图、算不算得动"来 → 会问"候选边怎么生成？约束怎么写？会不会有一万个解？我笔记本行不行？" → 学完能独立跑 networkx+CP-SAT，产出候选集+稳定边+敏感性，破除 M4/M5。
- **12 报告与伦理**：带着"我算出来了怎么写成正常报告"来 → 会问"多解怎么在报告里表达？要不要承认做不完整？安全问题写不写？" → 学完能写确定/推测/未知分开、含不确定性量化的正常报告，并专业地表达任务边界。
- **NN 接口**：带着"逆向出来的图怎么证明工艺真成立"来 → 会问"物料能量衡算严格验证靠什么？" → 学完知道④层（DWSIM/IDAES/Aspen）是验证器不是拓扑恢复器，留作进阶。

### 依赖现状与开工前置（POC 后已更新）

- **已装并锁定**（uv + 本地 `.venv`，Python 3.12）：numpy==2.5.2、scipy==1.18.1、matplotlib==3.11.1、networkx==3.6.1、pyflowsheet==0.2.2、**pathfinding==1.0.1**（见下方坑）。ortools 按第 11 讲需要再加；graphviz 若用需另装 Windows 版 `dot.exe`。
- **⚠ 版本坑（POC 实测）**：pyflowsheet 0.2.2 自带的 `core/pathfinder.py::Pathfinder.process_node` 是旧签名（6 参），而 `pathfinding>=1.0.22` 的 `AStarFinder.check_neighbors` 用新签名（7 参）调它 → `TypeError: process_node() takes from 5 to 6 positional arguments but 7 were given`，自动布线直接崩。**修法：把 pathfinding 钉到 `==1.0.1`**（POC 实测通过，PFD 0.08s 渲染成功）。备选修法：给每条 stream 设 `manualRouting`（`stream.py` 里 `len(manualRouting)>0` 会完全绕过自动布线器），但逐段手算相对坐标较繁琐。
- pyflowsheet 0.2.2 的 `BitmapContext` 残缺（`circle`/`text` 空实现、缺 `startGroup`/`path`/`line` 等 `Flowsheet.draw` 要调的方法），**唯一可靠出口是 `SvgContext` → SVG**；SVG→PNG 需 cairosvg（Win 上要装 cairo 原生库），POC 阶段不引入，SVG 用浏览器直接看。
- **POC 产物**（`figures/`）：`poc_mccabe_thiele.png`（12 块理论板、进料板 6，数值验证 [OK]）、`poc_distillation_pfd.svg`（进料→泵→预热器→塔→馏出液/釜液）。脚本归档在 `scripts/poc-01_*`、`scripts/poc-02_*`。
