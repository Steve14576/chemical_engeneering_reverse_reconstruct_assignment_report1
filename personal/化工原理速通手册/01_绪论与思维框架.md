## 一、成品开场：这一讲结束你能做出什么

先别啃原理。这一讲学完，你能把三个人七嘴八舌的现场碎片，变成两样**能跑、能交**的东西。

### 成品 1：一张"带置信度的约束图"雏形

现场你听到的大概是这种话：「罐子底下接了根管子通到一个泵」、「泵出口拐弯后就看不见了」、「有根管子疑似绕回罐子，也可能是假的」。把这些话直接翻译成**图**：

- **节点（node）**：设备。`T-101`（罐）、`P-101`（泵）、`E-101`（换热器）。
- **边（edge）**：管线片段，带方向。`T-101 → P-101`。
- **边上的属性**：`confidence`（置信度 high/medium/low）、`confirmed`（两端是否都亲眼看到）。

这段代码现在就能跑（`scripts/lec01-01...py` 的实验 2）：

```python
import networkx as nx
G = nx.MultiDiGraph()
G.add_node("T-101", kind="tank")
G.add_node("P-101", kind="pump")
G.add_node("E-101", kind="hex")
G.add_edge("T-101", "P-101", confidence="high",   confirmed=True,  note="两端都直接看到")
G.add_edge("P-101", "E-101", confidence="medium", confirmed=False, note="出口拐弯后被遮挡，按走向推测")
G.add_edge("E-101", "T-101", confidence="low",    confirmed=False, note="疑似回流，也可能是假管")
```

跑完你能立刻查一件有用的事——**泵的进出口齐不齐**：

```python
for n, kind in G.nodes(data="kind"):
    if kind == "pump":
        print(n, "in", G.in_degree(n), "out", G.out_degree(n))
```

实测输出 `P-101 in 1 out 1`：入口、出口各一条，合理。（为什么泵必须有进有出？第 03 讲讲透；现在先记住——**这是个能自动检查的"规矩"**。）

> **networkx 是什么**：Python 里专门处理"图"（节点 + 边）的库。`MultiDiGraph` = 有向图（边有方向）且允许两节点之间有多条边。你现在只需知道"它是拿来存和查这种连接关系的工具"，第 11 讲会真正用它建模、求解。

### 成品 2：一把能算的尺子——物料衡算

给你一个分离装置：进料 100 kmol/h、含轻组分 50%，分成两股，一股浓到 95%、一股稀到 5%。问两股各多少流量？手算和代码都给出 **$D=W=50$ kmol/h**，而且"进料 = 出料""轻组分进料 = 轻组分出料"两个守恒都闭合到 1e-15（机器精度）。这把尺子第四节讲透。

看到没——**这一讲不碰任何具体设备细节，你已经能建图、能算账了**。后面每一讲，都是往这张图里加一类设备、往这把尺子里加一条约束。

## 二、化工原理到底研究什么：单元操作心智模型

**理解层次：直（建立直觉）**

先破一个可能的误会：化工原理**不是**研究"某个具体化工厂怎么开车"。它研究的是——**所有化工生产里反复出现的那几类"物理加工动作"**。

不管你是造塑料、炼油、做药、酿酒，拆开看，无非是这几类动作在排列组合：

- 把液体/气体**送**过去（流体流动、泵）；
- 把两股流体**换热**（传热、换热器）；
- 把液体里的组分**分开**（蒸馏、吸收、萃取）；
- 把固体颗粒从气/液里**分出来**（沉降、过滤）；
- 把溶剂**蒸掉**（蒸发）；
- 把湿物料**弄干**（干燥）。

每一类这样的"通用物理加工动作"，就叫一个**单元操作**（unit operation）。**这是化工原理这门课的骨架**：整本教材基本就是一个单元操作一章。

> **为什么这个心智模型对你逆向作业至关重要**：现场那套装置，本质是**若干单元操作用管子串起来**。你要逆向的"拓扑"，就是"哪几个单元操作、按什么顺序、用哪根管连起来"。所以认设备的本质，是**认出它属于哪个单元操作**——认出"这是个换热器"，你就自动知道它有两套进出口（第 05 讲）；认出"这是个精馏塔"，你就知道它顶上有冷凝器、底下有再沸器（第 06 讲）。**设备认对了，约束就自动来了。**

本课大纲（见 `00_导览.md`）就是按单元操作铺开的：流体流动 → 输送机械 → 传热 → 蒸馏 → 吸收 → 分离 → 蒸发 → 萃取 → 干燥。主线批先教作业最常撞见的那几个，手册批补全。

## 三、这作业到底在"逆"什么

**理解层次：用（要会用这套图语言）**

**拓扑**（topology）这个词，在这里说人话就是：**谁连着谁、朝哪个方向连**。不管管子多长、多粗、拐几个弯、在哪层楼——只关心"连接关系本身"。把管子拉直、把楼层拍平，连接关系不变，拓扑就不变。

所以这个作业翻译成人话：**给你一堆现场碎片观察，重建出"设备—管线"的连接关系图。**

这件事为什么难（也正是为什么要用这门课的方法）：

1. **信息不全**：有的连接被遮挡、被楼层铁板挡住、追一半就断了。
2. **有假管/断管**：外观和真管一样，但根本不通。
3. **三个人各看一段**：得先把三份碎片对齐、去重、标冲突。

> **打破常见误会（M3）：图上连通 ≠ 工艺可行。** 很多人以为"把看到的管子连起来、图上连通了就对了"。错。一根管子把泵出口直接接回泵入口，图是连通的，但工艺上是废的（第 03 讲会讲为什么）。所以逆向不只是"连线"，还要用化工原理给每条连线**加约束、打分**——这正是后面 02~10 讲要喂给你的东西。

> **打破常见误会（M1）：空间近 ≠ 工艺相连。** 也别以为"两个接口挨得近就是连着的"。现场一根管从 A 设备旁边路过，不代表它接进 A。判断连不连，靠的是走向、法兰/焊口、介质、压头这些证据（第 02、04 讲），不是靠距离。

于是这作业的标准打法（本课把它讲透）：

```
碎片观察  →  实体对齐（三个人说的是不是同一个东西）
          →  建带置信度的约束图（节点/边/属性）
          →  候选边生成（物理上可能的连接）
          →  求解（选最可能的一组）+ 枚举多个候选
          →  稳定边统计 + 敏感性分析
          →  报告（确定/推测/未知分开写）
```

第 11 讲会把中间"建图 → 求解 → 统计"用 networkx + OR-Tools 跑通。**这一讲你只要先接受一件事：这作业是个"带不确定性的图重建问题"，不是猜谜，也不是密码学。**

## 四、物料衡算：整个化工的第一把尺子

**理解层次：推（要能手算）**

### 4.1 它是什么，凭什么成立

**物料衡算**（material balance / mass balance）说人话就是**质量守恒**套在一个流程上：**进多少，出多少；不出不入，就是积累。**

对一个**稳态**（steady state，指各点的流量、温度、组成都不随时间变——开机稳定运行后的常态）装置，积累 = 0，于是：

$$\text{进料总量} = \text{出料总量}$$

如果你还盯住其中**某一个组分**（比如混合物里的轻组分），无化学反应时它不会凭空产生或消失，于是对每个组分也有：

$$\text{某组分进料量} = \text{某组分出料量}$$

这两条就是物料衡算的全部。它是整个化工计算的地基——**任何流程，先能对上物料账，才谈得上合理。**

### 4.2 符号怎么说清（不空降）

拿一个"把进料分成两股"的分离装置举例（先不管它具体是什么设备，第 06 讲会告诉你这其实就是精馏塔；现在只练这把尺子）：

| 符号 | 是什么 | 单位 |
|---|---|---|
| $F$ | 进料流量（feed） | kmol/h |
| $D$ | 出料股 1 的流量 | kmol/h |
| $W$ | 出料股 2 的流量 | kmol/h |
| $x_F$ | 进料里**轻组分**的摩尔分数 | 无量纲（0~1） |
| $x_D$ | 出料股 1 里轻组分的摩尔分数 | 无量纲 |
| $x_W$ | 出料股 2 里轻组分的摩尔分数 | 无量纲 |

几个词当场说清：

- **kmol/h**：每小时多少"千摩尔"。摩尔（mol）是化学里"数粒子个数"的单位，1 mol ≈ $6.02\times10^{23}$ 个分子；kmol = 1000 mol。用它表示流量，就是"每小时流过多少物质的量"。
- **摩尔分数** $x$：混合物里某组分的摩尔数占总摩尔数的比例，0 到 1 之间。$x_F=0.5$ 就是"进料里一半（按摩尔数）是轻组分"。
- **轻组分 / 重组分**：混合物里容易挥发（沸点低）的叫轻组分，难挥发（沸点高）的叫重组分。分离装置的目的通常就是把轻组分往一股里富集、重组分往另一股里富集。

### 4.3 手算一遍（成品 2 的来历）

已知：$F=100$ kmol/h，$x_F=0.5$，$x_D=0.95$，$x_W=0.05$。求 $D$、$W$。

两个方程（总量守恒 + 轻组分守恒）：

$$F = D + W$$
$$F x_F = D x_D + W x_W$$

两个未知数两个方程，解它。把 $W = F - D$ 代入第二式：

$$F x_F = D x_D + (F-D) x_W$$
$$F x_F - F x_W = D\,(x_D - x_W)$$
$$D = F\,\frac{x_F - x_W}{x_D - x_W}$$

代数字：

$$D = 100 \times \frac{0.5 - 0.05}{0.95 - 0.05} = 100 \times \frac{0.45}{0.90} = 50 \text{ kmol/h}$$

$$W = F - D = 100 - 50 = 50 \text{ kmol/h}$$

**验证**（脚本 `lec01-01` 实验 1 实测）：

- 总量：$F-(D+W) = 100 - 100 = 0$（实测 `0.00e+00`）
- 轻组分：$F x_F - (D x_D + W x_W) = 50 - (50\times0.95 + 50\times0.05) = 50 - 50 = 0$（实测 `-7.11e-15`，机器精度下就是 0）
- 轻组分回收到出料股 1 的比例：$\dfrac{D x_D}{F x_F} = \dfrac{50\times0.95}{100\times0.5} = \dfrac{47.5}{50} = 95.0\%$（实测 `95.00%`）

$D=W=50$ 这么整，不是巧合：进料组成 $x_F=0.5$ 正好是 $x_D=0.95$ 和 $x_W=0.05$ 的**中点**，所以两股等量。**进料组成偏向哪一股，哪一股就出得多**——这个像跷跷板一样的直觉（正式名字叫"杠杆规则"）第 06 讲会用到，现在只需有这个感觉。

### 4.4 这把尺子怎么用在逆向作业上

- **自查流程讲不讲得通**：如果逆向出的拓扑里，某设备"进 100 出 60"又没有别的出口，物料账对不上，这条拓扑就可疑。
- **补全看不见的流量**：现场只测到几股流量，用守恒能反推没测到的那股。
- **报告里的硬数据**：$F=D+W$ 这种守恒关系，是报告里少数能"确定写死"的东西，比猜测的连接可靠得多。

> **一个诚实的边界**：物料衡算只能查"账对不对得上"，**不能告诉你连接对不对**。账对得上是**必要条件不是充分条件**——错误的拓扑也可能凑出对得上的账。所以它是"排除明显不合理"的筛子，不是"证明唯一正确"的钥匙（这正好呼应作业的多解困境，第 11、12 讲细讲）。

## 五、能量衡算：认识即可

**理解层次：知（知道有这回事 + 什么时候找它）**

物料衡算管"质量守恒"，还有一把平行的尺子管"能量守恒"，叫**能量衡算**（energy balance）：进系统的能量 = 出系统的能量 + 积累。化工里的能量主要以**热**（换热、蒸发要吸热）和**功**（泵对流体做功）的形式进出。

这一讲**你只需知道它存在、以及它和物料衡算是并列的两把尺子**。它涉及"焓"（读 hán，一个表示物质含热量多少的状态量）这类概念，展开需要一整块热力学基础——**本课把它放在 NN 讲的④层钩子**：当你逆向出拓扑、想进一步验证"这流程的热量和功到底平不平"时才需要它，那时用 DWSIM/Aspen 这类流程模拟器去跑，而不是手算。

现在跳过它不影响你干完作业。记住一句话：**物料账先对上，能量账是进阶。**

## 六、确定/推测/未知：置信度分级与线型语义

**理解层次：用（要会用这套记录纪律）**

这是本作业**最重要的方法论**，也是让你报告"诚实又交得了差"的关键。核心一句话：

> **把"我亲眼确认的"、"我根据走向推测的"、"我根本看不到的"三类东西，从记录那一刻起就分开，绝不混为一谈。**

### 6.1 三级置信度

| 级别 | 什么意思 | 例子 |
|---|---|---|
| **高（确认）** | 两端都直接看到，连接连续无遮挡 | "罐底法兰 → 管 → 泵入口，全程可见" |
| **中（推测）** | 一端可见，另一端靠走向/附件推 | "泵出口管朝换热器方向走，但中间被挡" |
| **低（存疑）** | 只凭外观/位置/常识猜 | "有根管疑似绕回罐子，也可能是假管" |
| **未知** | 看不到，无法判断 | "管穿过二楼铁板后消失，终点不明" |

**纪律**：宁可标"未知"，也不要把"看起来相连"写成"确定相连"。工程上确实如此——**把猜测伪装成事实，是报告最致命的错**。

### 6.2 线型语义（画图时的统一约定）

把置信度落到图上，用不同线型表达，这样即使拓扑没完全还原，报告也能体现你辨识过程的严谨：

| 线型 | 含义 |
|---|---|
| 实线 ── | 现场直接确认 |
| 虚线 ┄┄ | 根据走向推测 |
| 点划线 ┈┅ | 可能的替代路径 |
| 叉号 ✗ | 断开、封堵或疑似假管 |
| 问号 ? | 连接关系未确认 |
| 阴影 / 虚框 | 无法进入或无法观察的区域 |

（第 04 讲会把这些线型落到正式的 P&ID 图上；第 11 讲会让求解器自动统计"哪些边在所有候选解里都出现"——那就是最该画实线的**稳定连接**。）

### 6.3 为什么这套纪律反而是你的护身符

作业要求"正常报告"，但现场条件（无图、拥挤、遮挡、假管）决定了你**不可能**得到唯一确定的完整拓扑——这类问题叫 **ill-posed（病态问题：问题本身就没有唯一确定的解，再多算法和算力也补不了信息缺口）**，第 12 讲细讲。与其硬编一张"看似完整其实全是猜"的图，不如：

- 确定的用实线画死；
- 推测的标虚线 + 置信度；
- 未知的老实标问号。

这样报告既满足格式，又经得起追问——**你展示的是"知道问题边界"的专业性，而不是"瞎猜"的运气。**

## 本讲小结

- **单元操作**：化工原理的骨架，指反复出现的通用物理加工动作（输送 / 传热 / 分离 / 蒸发 / 干燥…）。认设备 = 认它属于哪个单元操作，认对了约束就自动来。
- **拓扑逆向**：这作业是"带不确定性的图重建问题"——节点 = 设备，边 = 管线，属性 = 置信度。不是猜谜，不是密码学。
- **两个致命误会**：连通 ≠ 工艺可行（M3）；空间近 ≠ 工艺相连（M1）。
- **物料衡算**（第一把尺子，要会手算）：稳态无反应下，总量守恒 $F=D+W$、组分守恒 $F x_F = D x_D + W x_W$；能解两股出料流量、能自查流程是否自洽。**它只是筛子不是钥匙。**
- **能量衡算**：并列的第二把尺子，认识即可，进阶放④层。

**A.（数值题·物料衡算）** 真实场景：你要在报告里核对一股进料的分流是否合理。某分离装置进料 $F=200$ kmol/h、轻组分摩尔分数 $x_F=0.40$，测得两股出料组成为 $x_D=0.90$、$x_W=0.10$。求 $D$、$W$，并回代验证两个守恒。

<details><summary>参考答案</summary>

$$D = F\frac{x_F-x_W}{x_D-x_W} = 200\times\frac{0.40-0.10}{0.90-0.10} = 200\times\frac{0.30}{0.80} = 75 \text{ kmol/h}$$

$$W = F - D = 200 - 75 = 125 \text{ kmol/h}$$

验证：
- 总量：$D+W = 75+125 = 200 = F$ ✓
- 轻组分：$D x_D + W x_W = 75\times0.90 + 125\times0.10 = 67.5 + 12.5 = 80$；而 $F x_F = 200\times0.40 = 80$ ✓
- 轻组分回收到 D 的比例：$67.5 / 80 = 84.4\%$

（判据：两个守恒相减都等于 0。可自己按计算器或写两行代码复核。）
</details>

**C.（代码题·建图）** 用 networkx 把下面三个人的碎片观察建成一张 `MultiDiGraph`，节点带 `kind`，边带 `confidence` 和 `confirmed`，再写一段代码统计"确认边"和"待定边"各有哪些。观察：
- 甲：T-101（罐）底部接 P-101（泵）入口，全程可见。
- 乙：P-101 出口接管朝 E-101（换热器）走，中间被别的管挡住。
- 丙：E-101 有根管疑似绕回 T-101，但不确定是不是假管。

<details><summary>参考答案</summary>

```python
import networkx as nx
G = nx.MultiDiGraph()
G.add_node("T-101", kind="tank")
G.add_node("P-101", kind="pump")
G.add_node("E-101", kind="hex")
G.add_edge("T-101", "P-101", confidence="high",   confirmed=True)   # 甲：全程可见
G.add_edge("P-101", "E-101", confidence="medium", confirmed=False)  # 乙：被遮挡，推测
G.add_edge("E-101", "T-101", confidence="low",    confirmed=False)  # 丙：疑似回流/假管

stable  = [(u, v) for u, v, d in G.edges(data=True) if d["confirmed"]]
pending = [(u, v) for u, v, d in G.edges(data=True) if not d["confirmed"]]
print("stable :", stable)
print("pending:", pending)
```

实测输出（脚本 `lec01-01` 实验 2）：

```
stable : [('T-101', 'P-101')]
pending: [('P-101', 'E-101'), ('E-101', 'T-101')]
```

判据：能跑通、3 个节点 3 条边、`confirmed` 只有甲那条为 True。用到的都是本讲教过的 `add_node / add_edge / edges(data=True)`，没有超纲。
</details>

**D.（综合题·回扣成品）** 用一句话向不懂化工的队友解释：为什么"物料账对得上"不足以证明你逆向出的拓扑是对的？并举一个"账对得上但拓扑错"的具体小例子。

<details><summary>参考思路</summary>

物料衡算是**必要条件不是充分条件**：它只能筛掉"明显对不上账"的拓扑，筛不掉"账凑巧对得上、但连接是错的"那些。

小例子：把泵的出口直接接回泵自己的入口（形成 `T-101 → P-101 → 回 T-101` 的死循环）。只看"进 P-101 的量 = 出 P-101 的量"，物料账完全对得上，但这个流程是废的——泵在原地打转，没有任何物料被送到下游设备。可见"账平"不等于"流程合理"，还得靠工艺约束（第 03 讲：泵要有下游去向）和流向/能量判断来补。
</details>
