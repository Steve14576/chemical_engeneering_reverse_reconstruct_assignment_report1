# 化工原理速通手册 — 导览

> 一门**偏向"逆向化工实训装置拓扑"作业角度**的化工原理速通课。
> 它同时是**手册**：整套单元操作体系都在，随时翻得到。

## 这门课是什么

你面前有一套演示性化工容器管道装置，要在没图纸、没学过化工原理的情况下，把它的**拓扑结构**（哪个设备接哪根管、物料往哪流、哪根是假管/断管）逆向出来，写一份研究报告。

这门课干两件事：

1. **速通主线**：把干完这个作业**真正要用到**的化工原理，按"任务卡壳的那一刻"逐个教给你——够你看懂现场、认出设备、写出工艺约束、建图求解、写出报告。
2. **手册兜底**：把化工原理的**整套体系**（流体流动→输送→传热→蒸馏→吸收→分离→蒸发→萃取→干燥）地毯式覆盖，让你不至于"只会做这个作业、背后体系一无所知"。

两件事靠**理解层次三档标注**统一起来——不是每个知识点都要练成肌肉。

## 理解层次三档（贯穿全课，先记住）

| 标记 | 含义 | 你该怎么对待 |
|---|---|---|
| **推** | 要能推导 / 手算 | 核心技能，作业要练，考试要会 |
| **用** | 要会用 | 会套公式、会建模、会查表用 |
| **知** | 知道有这回事 + 什么时候找它 | 不用背，遇到知道去哪查（手册层） |
| **直** | 建立直觉 | 懂"它在干什么"，不抠细节 |

> 速通 = 只钻 **推** 和 **用** 两档；**知** 和 **直** 读一遍建立索引即可。这就是"时间不够又不想只懂皮毛"的解法。

## 前置

- 会基础 Python（变量、循环、函数、列表/字典）。用到 numpy/networkx 时当场解释，不假设你会。
- **不需要**任何化工、物理化学基础——本课从零讲，术语首次出现当场定义。
- 微积分：只用到"会看懂导数/积分符号"的程度，需要时会白话解释。

- [ ] 读懂并手绘简化 P&ID / 流程图，用实线/虚线/叉号/问号区分"确认/推测/断假管/未知"。
- [ ] 用化工原理常识写出工艺软约束（泵有吸入口排出口、罐底出料、排放通低点、仪表是支路、换热器两侧进出口），并说清**物理依据**。

- [ ] 写出一份**正常格式**、把确定/推测/无法判断分开、含不确定性量化的研究报告，并说明本任务的 ill-posed 边界。

## 怎么读这门课（双轨读法）

- **赶时间**：只读主线批 01–04、11、12，每讲只钻 **推**/**用** 档，**知**/**直** 档扫一眼即可 → 最快能干完作业。
- **要体系**：主线读完再补手册批 05–10，把每个单元操作过一遍 → 背后方法论完整。
- 每讲结构固定：**本讲怎么走（脉络图）→ 成品开场 → 拆解（概念在任务卡壳处引入）→ 小结 → 掌握度自测 → 作业**。看漏了随时靠脉络图定位。
